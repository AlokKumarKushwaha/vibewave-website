How do I install the APK file on Android?

Once downloaded, tap on the notification or open your phone's 'Downloads' folder. Tap the APK file and select 'Install'. If your phone asks for permission to install unknown apps, tap 'Settings' and enable 'Allow from this source'.

Is VibeWave free and ad-free?

Yes, 100% free and open-source without third-party advertisements or audio interruptions.

Which build should I select?

Select 'Standard' for Samsung, Pixel, OnePlus, Xiaomi, Realme, Motorola, etc. Select 'Vivo / iQOO' if you have a Vivo/iQOO phone running OriginOS / FuntouchOS to get dynamic island music widget support.
