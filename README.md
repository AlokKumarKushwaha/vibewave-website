# 🌊 VibeWave Music - Official Website

The official landing and download website for **VibeWave Music** — a modern, ad-free music streaming app for Android.

## 🔗 Live Demo
- **Website:** [https://vibewave-music.netlify.app](https://vibewave-music.netlify.app)

## 📁 Repository Structure
- `index.html` — Responsive landing page with interactive seasonal artwork, theme picker, and mobile download flow
- `qr-code.svg` / `qr-code.png` — High-resolution scannable QR code matrix for mobile cameras
- `downloads/` — APK release packages for Android (Standard, Vivo Island, ARMv7)
- `_redirects` — Netlify SPA & routing configuration
